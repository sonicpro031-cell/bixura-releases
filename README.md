# Bixura Desktop - releases

Здесь лежат установщики Bixura (v0.3.0+).

Файлы:
- Bixura-Setup-x64.exe — установщик (NSIS)
- Bixura-Portable-x64.exe — портативная версия

Приложение само проверяет обновления: GET /api/bixura-update на сайте Vionchiks
и сверяет SHA-512 скачанного файла.

Публичный репо обязателен: анонимные пользователи качают установщики
через редирект с сайта и не могут авторизоваться.
